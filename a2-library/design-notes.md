# Assignment 2 - Design Notes
## 1. My Fourth Item
My fourth item is an AppleLaptop, which extends LibraryItem and implements Borrowable. It has an additional field called ramGb to store its memory capacity. I chose a 7-day loan period and a $3.00 daily late fee because laptops are more expensive than books and DVDs, so a shorter borrowing period and higher late fee encourage members to return them on time.
## 2. Where Loans Live
I chose to store borrowing records in a separate Loan class, where each Loan contains an item, a member, and a due day. The Library manages these records using a Loan array, making it easier to track and update individual loans. I chose this instead of storing borrowing information directly in Member because each member can borrow multiple items with different due dates, which would be harder to organize and maintain.
## 3. Who Checks What
In my design, the Library class performs all six checks in the checkOut() method. It uses findMember() and findItem() to check whether the member and item exist, checks whether the item implements Borrowable, and uses findLoan() to determine whether it is already checked out. The Library also uses countLoansForMember() to enforce the five-item borrowing limit. Finally, the Member class stores unpaid fines, and the Library calls member.getFines() to check the unpaid balance and prevent borrowing when it exceeds $10.00.
